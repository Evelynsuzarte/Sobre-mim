# Sobre Mim — Evelyn Suzarte

Página pessoal desenvolvida em HTML, CSS e JavaScript puro para apresentar minha trajetória, experiências, stacks e projetos públicos do GitHub.

## Acesse a página publicada

👉 **[https://evelynsuzarte.github.io/Sobre-mim/](https://evelynsuzarte.github.io/Sobre-mim/)**

## Funcionalidades

- Apresentação pessoal, palavras-chave e links rápidos para **GitHub** e **LinkedIn**
- Seção **Sobre** organizada em cards informativos
- Seção **Experiências** em formato de linha do tempo
- Seção **Stacks & Tecnologias** separada entre conhecimentos atuais e tecnologias em estudo
- Seção **Projetos** integrada à API pública do GitHub com paginação em grade de 2 colunas
- Alternância entre **tema claro e tema escuro** com salvamento no navegador (`localStorage`)
- Efeito de abertura de **cortina de teatro** e animação nos selos
- Layout responsivo para desktop e celular
